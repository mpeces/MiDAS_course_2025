# MiDAS workshop 2025 MEWE, Atlanta
#### Application of the MiDAS reference databases and ampvis2 for microbial community analyses


## Content
This repository contains data, exercises, and presentations for the hands on part of the MiDAS workshop.
For the exercises we will be using the [ampvis2](https://kasperskytte.github.io/ampvis2/articles/ampvis2.html) package in Rstudio.
